# FT Darts V5.8.20 — Annonces Tour du monde

Contre l'ordinateur en Tour du monde :

1. le commentateur annonce les trois lancers de l'ordinateur ;
2. il ne dit plus de combien l'ordinateur a avancé ;
3. il annonce directement la prochaine cible du joueur.

Exemple :

`Ordinateur moyen joue 12, 13, OUT. À toi Fabien. Vise le 14.`

Si l'ordinateur termine :

`Ordinateur moyen termine le Tour du monde.`
